Hardware Passkey (FIDO2 / WebAuthn)

Bind a hardware security key, TouchID, or Windows Hello to this account. The authenticator signs a server-issued challenge with its private key, which never leaves the device. Passkeys must be enrolled per device — there is no shared or default credential.

Access Ledger

Every read of this client's file — yours, or an operator's with a co-signature — is recorded in a tamper-evident, hash-linked ledger. Deleting or altering any entry breaks the chain and is reported below.

Dual-Control Access

Administrators, auditors, and security officers cannot read client records on their own authority. Raw access requires an M-of-N co-signature from a second privileged principal, and every step is alerted and audited.

1 · Request Access

2 · Co-Sign a Request

A second privileged principal approves the request. Self-approval is rejected by the engine — the requester and the co-signer must be different accounts.
